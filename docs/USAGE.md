# FunAuth 使用指南

## 概述

FunAuth 是一个用于网易 Minecraft 3.9 租赁服的认证和管理工具，提供以下功能：
- **验证服务器**：作为中间人验证玩家身份
- **租赁服搜索**：搜索和查看可用的租赁服
- **加入租赁服**：获取进入租赁服所需的认证信息

## 组件说明

本项目包含两个主要可执行程序：

### 1. funauth-server (验证服务器)
用作本地验证服务器，处理玩家的登录请求。

### 2. funauth-client (租赁服客户端)
提供交互式菜单，用于搜索、查看和加入租赁服。

## 使用方法

### 运行验证服务器 (funauth-server)

```bash
./funauth-server
```

启动后，服务器将监听指定端口，等待客户端连接。

### 运行租赁服客户端 (funauth-client)

```bash
./funauth-client
```

启动后将显示主菜单，您可以选择以下操作：

#### 菜单选项说明

1. **设置 Cookie**
   - 输入您的网易登录 Cookie 进行认证
   - Cookie 是访问租赁服 API 的必要凭证

2. **搜索租赁服**
   - 输入租赁服名称关键词进行搜索
   - 显示匹配的租赁服列表

3. **查看可用租赁服列表**
   - 获取所有可用的租赁服列表
   - 显示租赁服 ID、名称和状态

4. **查看租赁服详情**
   - 输入租赁服 ID 查看详细信息
   - 包括在线人数、版本、类型等信息

5. **进入租赁服**
   - 输入租赁服 ID 和密码（如有）
   - 获取进入游戏所需的认证信息
   - 返回的响应包含服务器地址、端口、用户名和 Token

6. **退出**
   - 退出程序

## 获取 Cookie

1. 登录网易 Minecraft 官网
2. 打开浏览器开发者工具（F12）
3. 切换到 Network（网络）标签
4. 刷新页面或进行任意操作
5. 找到任意请求，查看 Request Headers
6. 复制 Cookie 字段的值

## 注意事项

- Cookie 是敏感信息，请妥善保管，不要分享给他人
- 部分租赁服可能需要密码才能进入
- 确保网络连接正常，以便访问网易 API
- 本工具仅供学习研究使用，请遵守相关法律法规和用户协议

## 常见问题

### Q: 提示"认证失败"怎么办？
A: 请检查 Cookie 是否正确且未过期，尝试重新获取 Cookie。

### Q: 搜索不到租赁服？
A: 请确认输入的关键词正确，或尝试其他关键词。

### Q: 进入租赁服时提示错误？
A: 请确认租赁服 ID 正确，如有密码请确保密码正确。
